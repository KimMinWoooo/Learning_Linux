# 🐧 Linux Log Lifecycle Automation with Bash & Cron

> **리눅스 환경에서 발생하는 대량의 시스템 및 서비스 로그를 보관 주기에 따라 자동으로 압축·삭제하고, Cron 스케줄러를 통해 24/7 무중단 운영을 보장하는 자동화 파이프라인 구축 프로젝트**

---

## 📌 1. 프로젝트 배경 및 목적

### ❓ 쉘 스크립트(Shell Script)란?
리눅스/유닉스 쉘(Bash 등)에서 실행 가능한 명령어들을 파일로 묶어 순차적으로 실행하는 스크립트 언어입니다. 반복적인 운영체제(OS) 명령어 작업을 프로그래밍 방식으로 제어(`if`, `for`, 함수 등)할 수 있습니다.

### 🎯 왜 쉘 스크립트와 자동화가 필요한가?
* **디스크 풀(Full) 장애 사전 방지**: 서비스가 24시간 실행되면 로그가 무한히 누적되어 디스크 용량이 100%에 도달하는 장애가 빈번히 발생합니다.
* **단순 명령 일괄 실행을 넘어선 비즈니스 로직**: 단순히 명령어를 모아두는 것에 그치지 않고, "7일 이상은 압축하여 디스크 절약, 30일 이상은 영구 삭제"와 같은 명확한 데이터 라이프사이클 정책을 OS 레벨에서 강제합니다.
* **DevOps & 운영 효율성(Operational Efficiency)**: 사람이 매일 접속해서 로그를 수동으로 지우는 것은 휴먼 에러를 유발합니다. 스케줄러와 연계하여 **사람의 개입이 필요 없는 완전 무인 자동화 환경**을 구축하는 것이 신뢰성 엔지니어링(SRE)의 핵심입니다.

## 🛠️ 2. 로그 라이프사이클 관리 정책 (Data Lifecycle)

| 대상 파일 | 경과 기간 | 처리 방식 | 목적 |
| :--- | :--- | :--- | :--- |
| `*.log` (최신) | 0 ~ 7일 미만 | **원본 유지** | 실시간 트러블슈팅 및 서비스 접근 유지 |
| `*.log` | 7일 이상 경과 | **`gzip` 압축 (`.log.gz`)** | 텍스트 압축(약 80~90% 용량 절감)으로 디스크 공간 확보 |
| `*.gz`, `*.log` | 30일 이상 경과 | **영구 삭제 (`rm`)** | 법적/운영상 보관 주기가 지난 불필요 데이터 정리 |
| `manager_execution.log` | - | **삭제/압축 대상에서 제외** | 스크립트 자체의 실행 이력 보존 (`! -name`) |

## 📂 3. 프로젝트 구조

```text
├── /home/minwoo/
│   └── log_manager.sh                  # 로그 라이프사이클 자동 관리 스크립트
└── /var/log/my-services/               # 서비스 로그 수집 디렉터리
    ├── app_today.log                   # [유지] 오늘 생성된 로그
    ├── access_today.log                # [유지] 오늘 생성된 로그
    ├── app_10d.log.gz                  # [압축] 10일 경과 로그 (압축 완료)
    └── manager_execution.log           # [기록] 자동화 작업 실행 기록
```
